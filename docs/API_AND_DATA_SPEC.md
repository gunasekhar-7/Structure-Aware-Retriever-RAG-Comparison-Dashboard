# 📋 API & Data Contract Specification

This document details the data schemas, file formats, and Python class interfaces used throughout the STAIR pipeline.

---

## 1. Data Contract Specifications

### 1.1 Document Index (`data/toc_and_sections.json`)
The canonical structured representation extracted from technical documentation PDFs.

```json
{
  "toc_prompt": "# Python 3.11 & FastAPI Production Guide\nChapter 1: Core Architecture\n    leaf Section 1.1: Syntax, Operators & Flow Control\n...",
  "leaves": {
    "Section 1.1: Syntax, Operators & Flow Control": "Complete un-truncated section text including code blocks, function signatures, and tables...\n",
    "Section 1.2: Iterators & Context Managers": "..."
  },
  "source": "pdf_extraction",
  "num_leaves": 9
}
```

#### Field Definitions:
- `toc_prompt` (`str`): Formatted Table of Contents where leaf nodes are prefixed with `leaf `.
- `leaves` (`dict[str, str]`): Mapping where keys match the exact clean leaf titles, and values are the complete, unbroken subsection text.
- `source` (`str`): Identifier of the extraction origin (`pdf_extraction` or `synthetic_sample`).
- `num_leaves` (`int`): Total count of indexed leaf sections.

---

### 1.2 Synthetic Training & Validation Pairs (`data/synthetic_qa_*.jsonl`)
Strictly conforms to Table 2 of the IBM STAIR paper. Stored as JSON Lines (JSONL).

```jsonl
{"prompt": "### Book: Python 3.11 & FastAPI Production Guide\nPick the best section from the table of contents below which can answer the user query below. Only generate the section name, do not generate any explanation!\n### Table of Contents\n# Python 3.11 & FastAPI Production Guide\n...\n### Query: How do task groups handle exceptions in Python 3.11?\n### Section: leaf ", "completion": "Section 3.2: Task Groups, Exception Handling & Deadlock Avoidance"}
```

#### Field Definitions:
- `prompt` (`str`): Multi-turn instruction containing book title, full Table of Contents, user query, and the completion prefix `### Section: leaf `.
- `completion` (`str`): Target leaf title without the `leaf ` prefix. During training, loss is computed only on these tokens.
